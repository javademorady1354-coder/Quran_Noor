# قرآن کریم – نور هدایت

پروژه اندرویدی آفلاین برای مطالعه قرآن کریم.

## وضعیت فعلی
این commit زیرساخت اولیه اندروید، رابط کاربری فارسی، فهرست ۱۱۴ سوره، ذخیره نشانک محلی و گردش‌کار ساخت APK را اضافه می‌کند.

**توجه:** این نسخه هنوز متن کامل آیات، صفحه‌بندی دقیق مصحف مدینه (۶۰۴ صفحه)، ترجمه‌های فارسی و تفاسیر را شامل نمی‌شود. این موارد تا زمان افزودن داده‌های کامل و بررسی مجوز بازنشر، فعال یا ادعا نمی‌شوند.

## ساخت APK
در GitHub به بخش Actions بروید و workflow با نام **Build Android APK** را اجرا کنید. پس از موفقیت، فایل APK در بخش Artifacts همان اجرای workflow قرار می‌گیرد.

## منبع متن قرآن
برای متن عربی از Tanzil Project استفاده خواهد شد. شرایط منبع الزام می‌کند متن بدون تغییر بازنشر شود، منبع و پیوند آن درج شود و اعلان مجوز حفظ گردد:
https://tanzil.net/docs/Text_License

## امکانات برنامه‌ریزی‌شده
- متن عثمانی مطابق مصحف مدینه و صفحه‌بندی ۶۰۴ صفحه‌ای
- ترجمه‌های فارسی با مجوز بازنشر معتبر
- تفاسیر با مجوز روشن
- جست‌وجو، نشانک، آخرین محل مطالعه و یادداشت
- حالت روشن/تیره و تنظیم اندازه قلم

## مجوزها
مجوز هر مجموعه داده باید جداگانه بررسی و در برنامه درج شود. وجود نام یک مترجم یا مفسر به‌تنهایی به معنی اجازه بازنشر متن اثر نیست.
